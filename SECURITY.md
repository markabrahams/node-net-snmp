# Security Policy

## Supported versions

Security fixes are made to the latest release of net-snmp only. Please make
sure you are using the latest version from npm before reporting an issue.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, report them privately through GitHub's
[private vulnerability reporting](https://github.com/markabrahams/node-net-snmp/security/advisories/new)
(the "Report a vulnerability" button on the repository's Security tab).

Please include:

* the version of net-snmp affected
* a description of the vulnerability and its impact
* the configuration needed to reproduce it (agent, receiver, session options,
  users or communities)
* runnable code or packets that demonstrate the problem

## What to expect

Reports are acknowledged as soon as practical. Once a vulnerability is
confirmed, a fix is developed privately and released to npm, and a GitHub
security advisory is published at the same time, with a CVE where
appropriate. Reporters are credited in the advisory unless they prefer
not to be.

Please keep the details private until the fix has been released and the
advisory published.
